Greenova Environmental Management Platform
==========================================

Greenova is a Django-based platform for managing environmental obligations, compliance, and reporting. The core app provides authentication, user management, audit trail, and shared utilities.

Key Features
------------
- Custom user and profile management
- Audit trail and logging
- django-allauth integration (MFA, FIDO2)
- Protobuf3 for data serialization
- SCSS and AssemblyScript for frontend
- High test coverage and type safety

See docs/CORE_APP.rst for core app details.
